# 대표 매체군 정부광고 연도 비교

**웹에서 2022~2026년의 모든 연도 조합을 비교하고 기사 생성·검수·승인까지 하려면 [ARTICLE_WORKFLOW.md](../ARTICLE_WORKFLOW.md)를 따릅니다.** 아래는 기존 BAT 실행 방식의 안내이며 기본 비교는 2024년 대비 2026년입니다.

**RUN_ANALYSIS.bat을 한 번 실행하면 2024년과 2026년을 함께 집계해 비교한다. 연도를 고쳐 두 번 실행할 필요가 없다.** 국가행정기관·공공기관의 광고에서 각 연도 파일의 광고시작일이 각각 9월 30일 이하인 내역을 사용한다.

2024년 금액·건수, 2026년 금액·건수, 증감액·증감 건수, 증감률, 전체 광고비에서 차지하는 비중과 그 변화를 계산한다. OpenAI API는 이 비교 팩트시트를 받아 기사 초안을 작성한다. 합계와 증감 계산은 Python이 수행한다.

## 기존 파일을 교체하고 실행하기

GitHub에서 최신 저장소 전체를 받았다면 아래 1~2번의 폴더 복사는 필요 없다. `media_analysis` 폴더에서 3번부터 실행한다. 처음 설치하는 PC는 먼저 상위 폴더의 [INSTALL.md](../INSTALL.md)에 따라 Python 환경을 준비한다.

1. 정부광고 프로그램 폴더를 연다. `app.py`, `database.py`, `data` 폴더가 있는 위치다.
2. 새 압축파일을 푼다. 그 안의 **media_analysis** 폴더를 1번 위치로 복사한다. 이미 같은 폴더가 있으면 **파일 덮어쓰기**를 선택한다. 기존 정부광고 폴더 전체를 교체하는 작업이 아니다.
3. `media_analysis` 폴더를 열어 **RUN_ANALYSIS.bat**을 더블클릭한다.
4. 창에 `2024년 자료를 집계합니다...`, `2026년 자료를 집계합니다...`가 차례로 나온다. 완료되면 브라우저에 **2024년 대비 2026년 정부광고 비교** 화면이 열린다.
5. 위쪽에서 매체군·개별 매체의 증감과 비중 변화를 확인한다. 아래쪽 개별 내역은 자료연도·매체군·매체·기관·검색어로 찾을 수 있다. 화면은 100행씩 표시하고 CSV에는 전체 내역을 저장한다.
6. 비교 기사도 만들려면 **WRITE_ARTICLE.bat**을 더블클릭한다. 기존 정부광고 폴더의 `.env`에 등록한 `OPENAI_API_KEY`를 사용한다. 한 번 실행할 때 한 번 요청하며 OpenAI API 사용료가 발생한다.

### 이번 결과가 저장되는 위치

결과는 **media_analysis/comparison_output** 폴더에 저장된다. 예전에 만든 2024년 단독 분석 결과 `output` 폴더가 남아 있어도 새 결과와 섞이지 않는다. 이번 비교 기사도 `comparison_output`에 저장된다.

| 파일 | 내용 |
| --- | --- |
| `report.html` | 두 연도 비교 화면과 전체 광고 내역 검색 |
| `fact_sheet.json` | 두 연도 집계·증감·조건·주의사항을 담은 기사 근거 |
| `all_ads.csv` | 두 연도의 선정 매체 광고 전체 내역. 자료연도 열 포함 |
| `all_ads_2024.csv`, `all_ads_2026.csv` | 연도별 전체 내역 |
| `comparison_summary.csv` | 10개 매체의 금액·건수·증감·비중 비교 |
| `group_comparison.csv` | 두 매체군의 비교 |
| `registered_names.csv` | 연도별 실제 합산 등록명과 매체구분 |
| `review_candidates.csv` | 유사 명칭·계열·대행 등 자동 합산하지 않은 후보 |
| `invalid_start_dates.csv` | 기관 조건에 맞지만 시작일을 판독하지 못한 행 |
| `article_draft.txt` | WRITE_ARTICLE.bat으로 실제 API 실행 후 생성되는 기사 |
| `article_generation_record.json` | 실제 API 실행 후 모델·프롬프트·근거·응답 ID·사용량 기록 |

`comparison_output`은 RUN_ANALYSIS.bat을 실행하면 본인 PC의 원자료와 설정으로 생성·갱신된다. 생성 결과는 Git에 포함하지 않는다. 입력 파일별 SHA-256을 팩트시트에 기록한다. 기사 파일은 API를 실제 실행해야 생긴다.

## 짧은 비교 기사 작성 기준

WRITE_ARTICLE.bat은 집계 결과에서 **인쇄·방송·인터넷을 각각 구분한 비교표를 Python으로 계산**해 API에 추가 전달한다. 같은 언론사의 종이신문과 인터넷 광고를 합쳐 기사에 쓰지 않도록 했다.

- 제목 1개와 본문 3문단, 본문 공백 포함 약 800자 안팎으로 요청한다. 첫 문단은 비교 배경과 인쇄, 둘째 문단은 방송, 셋째 문단은 인터넷의 변화를 다룬다.
- 본문은 `했습니다`, `였습니다`, `줄었습니다`, `늘었습니다` 같은 격식 있는 경어체로 작성한다.
- 금액 나열보다 건수 변화와 증감률을 우선하며, 건수 또는 금액 증감률의 절댓값이 10% 이상인 지표만 기사 후보로 선별한다. 기준연도 0으로 증감률을 계산할 수 없는 지표는 후보 선별에 쓰지 않는다.
- 대표 사례만 고르고 개별 매체명은 최대 3개로 제한한다. 금액은 필요한 경우에만 `약 17억 원`처럼 Python이 반올림한 표현을 사용한다. 금액 증감을 설명할 때는 두 연도 금액을 함께 제시하며, 증감률은 원값으로 미리 계산한 결과를 사용한다.
- 서두에 실제 비교 기간과 예산안 편성 주체를 고려한 배경을 설명하도록 했다. 2022~2026년 예산안의 공식 출처는 `budget_context.json`에 기록했다. 편성 배경을 개별 광고의 예산 출처나 선정 원인으로 단정하지 않는다.
- 현재 날짜 조건은 각 연도 파일의 광고시작일 9월 말 이하이며, 이전 연도 시작 광고도 포함한다. 따라서 정확한 1~9월 지급액이나 모든 광고의 예산 출처를 확인한 결과라고 쓰지 않는다.

추가한 유형별 계산과 API에 실제 전달한 전체 자료·지침은 실행 후 `article_generation_record.json`에 저장된다. 기존 `fact_sheet.json`과 조회 화면 집계는 변경하지 않는다. 글의 길이·문체·사례 선택은 모델에 요청하는 작성 지침이며, 실제 초안을 확인해야 한다.

예산안 편성 배경 근거:

- 2024년도 예산안, 대통령실, 2023-08-29: https://www.korea.kr/news/policyNewsView.do?newsId=148919495
- 2026년도 예산안, 기획재정부, 2025-08-29: https://www.korea.kr/news/policyNewsView.do?newsId=148948409

## 비교 기준

| 항목 | 2024년 | 2026년 |
| --- | --- | --- |
| 자료 | 2024년 원자료 파일 | 2026년 원자료 파일 |
| 광고시작일 상한 | 2024-09-30 포함 | 2026-09-30 포함 |
| 광고시작일 하한 | 기본 없음 | 기본 없음 |
| 기관 | 국가행정기관·공공기관 | 동일 |
| 선정 매체의 광고 유형 | 인쇄·인터넷·방송 | 동일 |
| 매체명 연결 | 아래 10개 매체의 정확 일치 목록 | 동일 |

- 보수 매체군: 조선일보, 중앙일보, 동아일보, TV조선, 채널A, MBN
- 진보 매체군: 한겨레, 경향신문, 오마이뉴스, 시민언론 민들레

이는 분석을 위한 대표 매체군이다. 모든 언론의 정치성향을 확정한 전수 분류가 아니다. 방송 3사와 오마이뉴스·민들레의 묶음은 사용자 분석 기획에 따른다. 주요 신문 분류의 참고 문헌과 한계는 `media_groups.json`과 결과 화면에 기록했다.

공백·대소문자 차이를 정규화한 뒤 **등록명 전체가 일치하는 경우에만** 연결한다. 본지와 설정된 뉴스사이트를 연결하되, 별도 계열 매체·잡지·대행·제작물은 미포함 후보에 남긴다. 매일경제·한국경제·문화일보 등은 이번 10개 대표 매체군에 자동 추가하지 않는다. 두 연도에 같은 연결 규칙을 적용한다.

## 숫자 읽는 방법

- **증감액 = 2026년 금액 − 2024년 금액**. 양수는 증가, 음수는 감소다.
- **금액 증감률 = 증감액 ÷ 2024년 금액 × 100**. 건수 증감률도 같은 방식이다. 2024년 금액이나 건수가 0이면 해당 증감률은 `계산 불가`다. 0에서 새로 생긴 것을 100% 증가라고 쓰지 않는다.
- **광고비 비중 = 해당 매체 금액 ÷ 그 연도 대상 전체 광고비 × 100**. 분모는 같은 기관·시작일 조건을 충족하는 모든 매체구분의 광고비다. 선정한 10개 매체의 합계가 아니다.
- **비중 변화 = 2026년 비중 − 2024년 비중**. 단위는 퍼센트포인트(%p)다. 금액이 줄어도 전체 광고비가 더 크게 줄면 비중은 높아질 수 있다.
- 비교는 2024년 대비 2026년이다. `전년 대비`라고 표현하지 않는다.

## 사용하는 원자료

기본 설정은 기존 정부광고 폴더의 다음 두 파일을 읽는다. MySQL을 실행하지 않아도 CSV로 분석할 수 있다.

```text
data/2024년도_정부광고집행내역_260930 기준.csv
data/2026년도_정부광고집행내역_260930 기준.csv
```

두 파일 중 하나라도 없으면 해당 연도를 알리는 오류로 중단한다. 없는 연도를 0원으로 처리하지 않는다.

## 나중에 조건을 바꾸려면

이번 2024년·2026년 비교에는 설정을 수정할 필요가 없다. 다른 비교를 할 때만 `settings.json`을 바꾸고 RUN_ANALYSIS.bat을 다시 실행한다.

- `year`: 기준연도. 기본 `"2024"`
- `compare_year`: 비교연도. 기본 `"2026"`
- `period_policy`: 기본 `year_pair`. 2026년이 포함되면 양쪽 9월 말 이하, 그 외는 각 연도 파일 전체로 자동 적용한다. 이 정책에서는 아래 날짜 입력을 사용하지 않고 하한도 두지 않는다. 웹 화면은 이 정책을 사용한다.
- `start_on_or_before`, `start_on_or_after`: 기존 BAT 방식에서 기간을 직접 지정하려면 `period_policy`를 `custom`으로 바꾸고 상한·하한을 지정한다. 비교연도에는 동일한 월·일을 적용한다. `null`은 해당 제한 없음이다.
- `org_types`: 기본 국가행정기관·공공기관. 지방행정기관·지방공기업·교육행정기관·특별법인·기타기관은 제외한다.
- `media_types`: 선정 매체에서 합산할 광고 유형. 기본 인쇄·인터넷·방송
- `source`: 기본 `csv`. `mysql`로 바꾸면 기존 `database.py`로 두 집행연도를 각각 조회한다. DB에는 SELECT만 실행한다.
- `openai_model`: 기존 기사 작성 예시와 같은 `gpt-4.1-mini`

매체 추가·제외와 등록명 연결은 `media_groups.json`, 기사 문체와 구성 지침은 `write_article.py`의 `PROMPT`에 있다. 설정이나 분류를 바꾼 뒤 집계를 다시 하지 않으면 기사 생성 전에 중단한다. 예전 단일연도 팩트시트도 기사 생성에 사용하지 않는다.

## 실행 오류가 날 때

더블클릭 창은 끝에서 멈춘다. 오류를 확인한 뒤 정부광고 프로그램에서 쓰던 Python 환경으로 실행한다. `.venv`가 있으면 배치 파일이 그 Python을 우선 사용한다.

터미널에서 직접 실행하려면 정부광고 폴더에서 입력한다.

```powershell
python media_analysis/run_analysis.py
python media_analysis/write_article.py
```

기존 안내대로 `.venv`를 사용하는 PC라면 위 `python` 대신 `.\.venv\Scripts\python.exe`를 사용한다. 기사 패키지가 없다는 메시지가 나올 때만 같은 Python으로 설치한다.

```powershell
python -m pip install --upgrade openai python-dotenv
```

CSV 집계는 Python 표준 기능만 사용한다. MySQL 모드는 기존 DB 설정과 `pymysql`이 필요하다. API 키는 다른 사람에게 보내지 않는다.

## 해석상 주의점

- **광고시작일 기준**이다. 보유 CSV에는 수탁일자·지급일자가 없으므로 정확한 1~9월 수탁액·실제 지급액과 같다고 할 수 없다. 시작일 하한이 없어 이전 연도 시작 광고도 포함되며 결과에 별도 표시한다.
- 금액은 `총계(VAT포함)` 전액이다. 광고기간에 따라 안분하지 않는다. 건수는 원자료 행 수이며 고유 캠페인 수가 아니다.
- 시작일을 판독하지 못하면 제외하고 별도 CSV에 남긴다. 금액을 판독하지 못하면 오류로 중단한다.
- 모든 항목이 같은 행도 임의 삭제하지 않고 추가 동일 행 수를 기록한다. DB 중복 적재 여부는 CSV 결과와 대조한다.
- 0행은 해당 자료·선정 조건에서 조회되지 않았다는 뜻이다. 그 매체가 정부광고를 전혀 받지 않았다고 단정하지 않는다.
- 집계 차이만으로 정권별 특혜·차별이나 예산편성·매체선정 원인을 입증하지 않는다. 기사 지침에도 이 제한을 넣었다.
