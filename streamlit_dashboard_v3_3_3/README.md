# 정부광고 데이터 대시보드 v3.3.3

2022~2026년 정부광고 집행내역 CSV를 분석하는 **Streamlit 대시보드**입니다. 광고금액·광고 건수를 연도, 매체, 기관별로 비교하고, CSV에 있는 수치를 직접 조회·계산하는 질문 기능을 제공합니다.

> **집계 기준**: 각 파일에서 `광고시작일`이 해당 연도인 행만 사용합니다. 광고금액은 `총계(VAT포함)` 열을 합산하며, 광고 건수는 해당 조건의 행 수입니다. 실제 대금 지급일이나 회계상 지출 시점을 의미하지 않습니다.
>
> **2026년 주의**: 2026년 CSV는 **2026년 9월 30일 기준 공개본**입니다. 파일에는 10~12월에 시작하는 광고 기록도 일부 있으므로 연간 확정 집계로 취급하거나 다른 연도와 같은 기간의 확정 실적으로 비교하면 안 됩니다.

## 어떤 기능이 있나요?

| 메뉴 | 하는 일 |
| --- | --- |
| 홈 | 연도별 광고금액과 매체별 비중을 한눈에 봅니다. |
| 무엇이 달라졌나 | 기준 연도와 비교 연도를 직접 선택해 광고비·건수·증감을 비교합니다. |
| 매체 흐름 | 인터넷·방송·인쇄·옥외·해외 매체별 연도 추이를 봅니다. |
| 기관 비교 | 기관분류나 기관명으로 검색하고 집행금액을 비교합니다. |
| 언론사 찾기 | CSV에 기록된 매체명을 검색해 광고금액과 원본 내역을 확인합니다. |
| 월별 변화 | 광고시작일을 기준으로 월별 추이를 비교합니다. |
| CSV 팩트체킹 | 질문에 맞는 광고 내역을 찾아 계산하고 사용한 조건·행을 제시합니다. |

## 설치 및 실행 (Windows / VS Code)

이 저장소의 상위 `data/` 폴더에는 2022~2026년 정부광고 CSV가 이미 들어 있습니다. **별도로 같은 파일을 이 폴더에 복사하지 않아도 됩니다.**

1. GitHub 저장소 전체를 내려받거나 복제합니다. **이 폴더만** 별도로 받는 경우에는 이 폴더 안에 `data/`를 만들고 CSV 5개를 넣어야 합니다.
2. VS Code에서 `streamlit_dashboard_v3_3_3` 폴더를 열고 터미널을 실행합니다.
3. 아래 명령어를 한 줄씩 실행합니다.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py --server.port 8506
```

브라우저 주소: <http://localhost:8506>

이미 다른 가상환경이 활성화되어 있고 `requirements.txt` 패키지 설치를 완료했다면 다음 명령어만 사용해도 됩니다.

```powershell
python -m streamlit run app.py --server.port 8506
```

종료할 때에는 VS Code 터미널에서 `Ctrl + C`를 누릅니다. 8506 포트가 사용 중이면 명령어의 번호를 다른 값으로 변경하세요.

## CSV 파일은 어디에서 읽나요?

프로그램이 아래 순서로 파일을 찾습니다.

1. `streamlit_dashboard_v3_3_3/data/`에 CSV가 있으면 그 파일을 우선 사용합니다.
2. 없다면 저장소의 공용 폴더인 `../data/`에서 2022~2026년 CSV를 읽습니다.
3. 둘 다 없으면 CSV 연결 안내가 표시됩니다.

원본 CSV 파일명은 `2022년도_정부광고집행내역_260930 기준.csv`처럼 **연도 숫자 4자리로 시작**해야 합니다. 업로드 기능은 임시 조회용이며 원본 파일을 덮어쓰지 않습니다.

필요한 주요 열은 `광고시작일`, `총계(VAT포함)`, `매체구분`입니다. 기관·매체 검색을 위해 `기관명`, `기관분류`, `매체명`, `광고명`도 사용합니다.

## CSV 질문 기능 사용 예시

- `2025년 정부광고 총액은 얼마인가요?`
- `2023년과 2025년 인터넷 광고금액은 얼마나 달라졌나요?`
- `2025년 경기도 광고비는?`
- `2025년 조선일보 광고비는?`
- `2025년 광고 매체를 선정한 이유는 무엇인가요?`

`경기도`처럼 여러 기관명에 공통으로 들어가는 표현을 사용하면 **기관 하나 / 여러 기관 / 이름이 일치하는 기관 전체** 중 계산 범위를 선택하게 합니다. 예를 들어 경기도청과 경기도교육청은 서로 다른 기관입니다. 이름에 `경기도`가 포함된 기관 전체를 합산한다고 해서 경기도에 소재한 모든 기관의 지출을 의미하지는 않습니다.

### 답변을 어떻게 확인하나요?

결과와 함께 **사용한 검색 조건, 해당 원본 행 수, 원본 데이터 미리보기와 CSV 내보내기**를 확인합니다. 질문 속 기관이나 매체를 찾지 못하면 전국 광고비로 대신 답하지 않습니다.

**중요:** 집행내역 CSV에는 매체 선정 사유, 심사 기준, 광고 효과, 예산 편성의 근거가 들어 있지 않습니다. 이런 질문에는 수치를 추측하거나 근거 없이 이유를 만들어 답하지 않습니다. 해당 내용을 확인하려면 정보공개 회신이나 선정 관련 문서 등 다른 근거자료가 필요합니다.

### 기본 모드와 AI 해석 모드

- **기본 모드:** API 키나 추가 비용 없이 정해진 유형의 금액·건수·연도 비교·순위 질문을 처리합니다.
- **AI 해석 모드:** 긴 문장에서 검색 조건을 추출하기 위한 선택 기능입니다. OpenAI API 키와 별도 이용 요금이 필요할 수 있습니다. **광고금액과 광고 건수 계산 자체는 Python이 CSV로 수행**합니다.

기본 모드와 AI 해석 모드 모두 모든 문장을 이해할 수 있는 것은 아닙니다. 검색 조건을 확인한 다음 결과를 활용하세요. API 키를 코드나 GitHub에 올리지 마세요.

## 폴더 구성

```text
streamlit_dashboard_v3_3_3/
├── app.py             # 화면과 데이터 분석 기능
├── csv_qa.py          # 질문 해석·검증·CSV 집계 처리
├── requirements.txt   # 필요한 Python 패키지
└── README.md          # 현재 안내 문서
```

기존 FastAPI/MySQL 기반 정부광고 앱은 저장소 루트의 별도 프로젝트입니다. 이 Streamlit 대시보드는 **기존 앱을 덮어쓰지 않고 독립적으로 실행**됩니다.

## 버전 안내

**v3.3.3** — 원본 CSV에 없는 *매체 선정 이유·집행 사유·예산 편성 근거* 질문을 연도별 총액 질의로 잘못 해석하지 않도록 제한을 보완했습니다. 기존 집계 및 기관·매체명 선택 기능은 유지했습니다.

## 사용 시 유의사항

- 집계는 광고시작일 기준이며, 집행액 전액을 해당 시작 연도에 배정합니다.
- CSV에 등록된 문자열을 기준으로 검색하므로 같은 기관·언론사가 여러 명칭으로 기록됐을 가능성은 별도로 확인해야 합니다.
- `매체명`에는 언론사가 아닌 다른 광고 매체나 플랫폼도 포함될 수 있습니다. 검색 결과를 곧바로 언론사 순위라고 표현하지 마세요.
- 집계 수치가 취재 결과를 자동으로 보증하는 것은 아닙니다. 기사 작성 시 원본 행과 공공기관의 공식 자료를 재확인해야 합니다.
- 로컬 PC에서 동작 여부를 확인한 버전이며, **공개 웹서비스 배포는 별도 작업**입니다.
